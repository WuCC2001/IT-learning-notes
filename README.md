# IT learning notes
IT学习笔记

现在的问题不是因为学习资源的不足，而是学习资源太多了，要从海量的学习资源中筛选出真正能帮到自己的，真的特别费时费力。

有些学习资源或网站可能比较火，比较热门，但真正上手了却发现不一定适合自己。所以在选择或筛选这一块，需要根据自己的需求和目的好好花功夫。我的一个经验就是，比如对同一个算法或题目的讲解，进行横向比较，然后选择自己最喜欢、或最适合自己的风格。如果没这么做过的朋友可以试一试。
